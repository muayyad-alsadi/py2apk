# Facts: Use a slice as a value

Verified against the compiler at this checkout. Line numbers are the
current definitions. Do not treat a slice object, a tuple of slices,
or slice assignment as supported.

## What compiles today

- `for item in items[1:]` compiles. `_for_statement`
  (`Py2APK/compiler_j/loops.py:81`) peels an `ast.Subscript` whose
  `slice` is `ast.Slice`, evaluates the sequence, then calls
  `_for_index` (`loops.py:224`). It does not build a copied sequence.
- Bounds are `invokestatic py2apk/slice_start(IIII)I` and
  `py2apk/slice_stop(IIII)I`, emitted by `_emit_slice_bound`
  (`loops.py:268`).
- Missing step becomes `1`. Literal step `0` raises
  `slice step cannot be zero` (`loops.py:220`). A non-literal step is
  checked at run time with `IllegalArgumentException`
  (`_emit_slice_step`, `loops.py:212`, and again in
  `_reject_zero_step`, `loops.py:250`). Keep both checks. The second
  one is redundant; deleting it changes `for` bytecode.
- A positive step stops with `if_icmpge`. A negative step stops with
  `if_icmple` (`loops.py:139`). `items[::-1]` walks backward.
- Bound expressions must leave `I`. `_emit_int_expr` (`loops.py:234`)
  raises `slice bound must be int`. That same helper typechecks a
  non-literal step, so a non-int step uses that same string.
- `_literal_int` (`Py2APK/compiler_j/types.py:232`) folds `int`
  constants, unary `+` / `-`, and `bool` (`True` → `1`, `False` → `0`).
  It is a module function, also used by `_emit_range_step`
  (`loops.py:322`). Do not move it.
- A generator slice stays rejected at `loops.py:95`:
  `a slice of a generator is unsupported`.
- `items[0]` loads. `items[0] = x` stores for arrays and `ArrayList`.
  A slice in load, type, or store raises
  `a slice is only supported as a for iterable`
  (`collections.py:54`, `collections.py:73`, `collections.py:103`).
- String index load is `charAt(I)C` and the descriptor is `I`
  (`collections.py:60`). A string slice must return `_STRING`, not `I`.

## Bound helper

`Py2APK/stdlib/py2apk.py` `slice_start` (`:19`), `slice_stop` (`:27`),
and `_adjust` (`:35`) are the compiler's `slice.indices`.

- `present` is `0` when that bound was omitted.
- Omitted start is `0` when step is positive and `length - 1` when
  step is negative. Omitted stop is `length` or `-1` the same way.
- A negative bound adds `length`. Still below `0` clamps to `0`
  (positive step) or `-1` (negative step). A bound past `length`
  clamps to `length` or `length - 1`.
- Clamping does not swap inverted bounds. `a[5:2]` on a length-5
  sequence becomes start `5`, stop `2`. Python's result is empty.
  Java `substring` and `Arrays.copyOfRange` throw when start > stop.
  The fast path must branch before those calls.

Do not edit this file. Do not add `slice_copy` or any other
Python-visible function. No `touch` of `Py2APK/stdlib` is required.

## Sequence descriptors

- Immutable list and homogeneous tuple literals are Java arrays.
  `_list_literal` (`collections.py:477`) calls
  `_java_array` (`collections.py:514`) unless the list is mutable.
  `_tuple_literal` (`collections.py:474`) is always `_java_array`.
  The descriptor is
  `[T` from `_array_descriptor`.
- A list is `arraylist:{element}` only when `_classify_lists`
  (`collections.py:321`) marks it mutable (append, field, captured,
  or an escaping call that does not accept the array). `_array_list`
  (`collections.py:180`) returns that pseudo descriptor.
- `_sequence_element` (`base.py:179`) understands `arraylist:` and
  `[`. It returns `None` for `String`, `HashSet`, and dicts. String
  subscript is a special case beside that helper.
- `_emit_sequence_length` (`loops.py:286`) emits `arraylength` or
  `ArrayList.size()I`. It does not handle `String`. `_emit_len`
  (`compare.py:251`) does, via catalogued `String.length`.
- `_NEWARRAY` (`types.py:69`) is `Z I F D J` only. Other components
  use `anewarray`. `_ARRAY_LOAD` / `_ARRAY_STORE` (`types.py:71` and
  `:79`) match those primitives and fall back to `aaload` / `aastore`.
- `_Compiler` (`compiler.py:22`) inherits `_LoopsMixin` and
  `_CollectionsMixin` before `_CompilerBase`. A collections method
  can already call `self._emit_slice_step`. Move the shared emitters
  onto `_CompilerBase` anyway so the slice-value path does not reach
  into the loop mixin. Leave the gather loops on `_CollectionsMixin`.
- `_cursor_name` (`base.py:168`) increments `for_serial` on every
  call. `_for_index` allocates `seq`, `len`, `step`, `start`, `stop`,
  and `idx` before it emits bounds. Do not reorder those calls.

## JDK methods the fast path needs

Absent from `tests/_compile_helpers.py` `_alias_catalog` (`:178`) and
from `_collection_catalog` (`:352`). `String.length` is already in
`_alias_catalog` (`:193`). `substring` is not. `java/util/Arrays` is
not in the repo at all.

`javap` on `~/.cache/py2apk/platforms/34/android.jar` shows:

- `String.substring(int, int) -> String`
  (also a one-arg `substring(int)`; do not use it)
- `Arrays.copyOfRange` for `byte short int long char float double
  boolean`, plus erased `<T> T[] copyOfRange(T[], int, int)`

Templates set `minSdkVersion` to 21, 23, or 33. Both methods exist
there. `_reject_newer_api` (`calls.py:153`) runs on `ast.Call` only,
not on a compiler-emitted `_require_method`. Still resolve the new
calls with `_require_method` (`base.py:220`) and emit with
`_invoke` (`base.py:241`). Do not call `_static_invoke`: it
re-emits arguments from a `Call` node.

Reference `copyOfRange` returns `Object[]`. Follow `_emit_to_array`
(`collections.py:302`): `checkcast` back to the source array
descriptor. Primitive overloads already return the primitive array.

`charAt` and `String.<init>([C)V` are emitted as raw instructions
today (`collections.py:60`, `_emit_char_string` in `calls.py:622`).
No catalog row. The non-unit string gather uses those same
instructions. `StringBuilder.append(I)` is in the catalog and would
append decimal digits. Do not use it for characters.

## Docs that still reject the value

- `docs/covered.md:130` and `:135`: a slice is only legal as a `for`
  iterable; `taken = items[:10]` does not compile.
- `docs/not-covered.md:44` is the snippet `tail = label[1:]`.
  `:55` says a slice does not compile except as the iterable of
  `for`.
- `ROADMAP.md:216` says `slice_start` / `slice_stop` normalize a
  `for` slice only.
